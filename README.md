## Environment

On this project I'm using a Docker compose file to provide one enviroment using Symfony6 - But how you can see on the image below I disable the phpmyadmin and mysql containers, because the project is not using it.

![image](https://github.com/fcosantosjournal/leaseweb-test/assets/54321059/821693ee-857c-4634-a041-2bebd8b2772a)

### Env file configuration

### Estructure Files, folders and more.

I used annotations to create the routes.

![image](https://github.com/fcosantosjournal/leaseweb-test/assets/54321059/f615b4b5-013d-465f-a2c5-d18d5a3f5aa6)

I created the project using a template to return the data and using four services to split up the business logic, because I tried to stay clean and the spec mentioned that they didn't have any plans to put this in a database, I decided not to create entities or repositories, but of course it's completely possible to do so.

![image](https://github.com/fcosantosjournal/leaseweb-test/assets/54321059/6c5d35ea-1155-4f2b-879c-8919c164c658)

The public folder contains the files for the frontend and the upload files, so that it's easy to create other functionalities in the future to replace the xlsx files, for example.
I used vanilla js so as not to create dependencies, for example to create the filters, I created everything using PHP, but I know it's possible to use many JS libraries to do this.

![image](https://github.com/fcosantosjournal/leaseweb-test/assets/54321059/27b76acf-de3e-4115-bcb0-8b74ff17c54b)

I created two twig files to receive the data from PHP and I didn't create any components because I thought it wasn't necessary.
